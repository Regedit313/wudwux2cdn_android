# wudwux2cdn_android

## Installation

1. Install Termux.

2. Copy the "wudwux2cdn_android" folder to the root of internal storage.

3. Open Termux and run:

termux-setup-storage

(When prompted, allow Termux to access all files on your device storage.)

4. Start wudwux2cdn:

bash ~/storage/shared/wudwux2cdn_android/wudwux2cdn.sh

(The scripts can be launched from any location in Termux.)

5. IMPORTANT:

For the first use, before the first extraction, select:

9 = Run first-time setup (required before first use)

This step installs all required dependencies and prepares the project folders.

The first-time setup must be completed before the first extraction.

---

## Menu

When started, wudwux2cdn.sh provides the following options:

1 = Extract WUD/WUX files

2 = Create common.key

3 = Create title key file

9 = Run first-time setup (required before first use)

0 = Exit

---

## Extract WUD/WUX Files

Place one or more .wud or .wux files inside:

auto_in/

When option 1 is selected, the script automatically:

- Searches for commonkey/common.key
- Searches for a matching title key file
- Requests missing keys through interactive prompts
- Extracts the game using JWUDTool
- Stores extracted files in auto_out/
- Removes the TitleID subfolder automatically

Successfully extracted .wud/.wux files are automatically removed from auto_in/.

If a matching title key file was placed in auto_in/, it is also automatically removed after a successful extraction.

---

## Create common.key

Option 2 creates:

commonkey/common.key

The key is entered manually through a prompt.

The created common.key will automatically be used by future extractions.

If no common.key exists when extracting a game, the script will request it manually.

If the extraction succeeds, the manually entered common key is automatically saved as:

commonkey/common.key

for future use.

---

## Create Title Key Files

Option 3 creates title key files inside:

titlekeys/

Examples:

Zelda.wux → Zelda.key

Mario Kart 8.wud → Mario Kart 8.key

game → game.key

The title key is entered manually through a prompt.

Multiple title key files can be created without leaving the menu.

---

## Input

Place one game image per file inside:

auto_in/

Example:

auto_in/

---- Zelda.wux

---- Mario Kart 8.wud

Optional title key files:

titlekeys/

---- Zelda.key

---- Mario Kart 8.key

Optional title key files can also be placed directly inside auto_in/ using the same filename as the game.

Example:

auto_in/

---- Zelda.wux

---- Zelda.key

Optional common key:

commonkey/

---- common.key

auto_out/

-------- 00000001.app

-------- 00000002.app

-------- 00000003.app

-------- 00000003.h3

-------- title.cert

-------- title.tik

---- Mario Kart 8/

-------- 00000000.app

-------- 00000001.app

-------- title.cert

-------- title.tik

-------- title.tmd

The TitleID folder generated by JWUDTool is automatically removed so that all extracted files are placed directly inside the game folder.

This structure can be copied directly to:

install/

for use with WUP Installer GX2.

## Notes

The required folders are automatically created if they do not already exist.

The script searches for common.key only in:

commonkey/

If no common.key is found, the key is requested manually.

A manually entered common key is automatically saved to:

commonkey/common.key

after a successful extraction.

The script searches for title key files in:

1. auto_in/
2. titlekeys/

If no matching title key file is found, the key is requested manually.

The title key filename must match the game filename.

Examples:

Zelda.wux → Zelda.key

Mario Kart 8.wud → Mario Kart 8.key

Title key files stored in titlekeys/ are kept for future extractions.

Title key files stored in auto_in/ are automatically removed after a successful extraction.

If an extraction fails, the original files remain untouched for troubleshooting.
